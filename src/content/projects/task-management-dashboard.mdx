# Task & Project Management Dashboard

## 1. Ringkasan Proyek
Dashboard web interaktif untuk membantu tim kecil dan pengembang independen mengorganisir tugas harian dan memantau status proyek secara efisien.

## 2. Masalah yang Dihadapi
Tugas yang tersebar di banyak catatan sering menyebabkan ketidakjelasan prioritas dan *missed deadlines*.

## 3. Solusi
Aplikasi berbasis **React + TypeScript** yang menerapkan sistem visual Kanban Board:
- Kolom status (To Do, In Progress, Review, Completed).
- Manajemen state terstruktur menggunakan **Zustand** untuk reaktivitas tinggi tanpa overhead re-render berlebih.

## 4. Fitur Utama
* **Kanban Board View:** Pengelompokan tugas berdasarkan tingkat penyelesaian.
* **Filter Prioritas:** Menyaring tugas berdasarkan prioritas (High, Medium, Low).
* **Keyboard Shortcut:** Akses cepat untuk menambahkan tugas baru.
* **Dark Mode Native:** Tampilan antarmuka yang ramah di mata untuk penggunaan malam hari.

## 5. Pembelajaran
Mengasah keahlian dalam optimasi performa React component re-rendering serta penanganan tipe data TypeScript yang ketat untuk state manajemen.
