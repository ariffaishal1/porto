# Personal Finance & Expense Tracker

## 1. Ringkasan Proyek
Aplikasi mobile ini membantu pengguna melacak aliran kas harian, mencatat setiap transaksi pengeluaran/pemasukan, dan menampilkan statistik anggaran bulanan.

## 2. Masalah yang Dihadapi
Banyak orang kesulitan mengontrol pengeluaran harian karena tidak adanya pencatatan otomatis yang mudah diakses tanpa memerlukan koneksi internet stabil.

## 3. Solusi
Aplikasi dikembangkan menggunakan **Flutter** dengan basis data offline-first **SQLite**:
- Memungkinkan pencatatan transaksi secara cepat kapan saja tanpa sinyal internet.
- Menampilkan grafik visualisasi pengeluaran bulanan menggunakan ringkasan statistik intuitif.

## 4. Fitur Utama
* **Offline-First Storage:** Data tersimpan aman secara lokal di perangkat pengguna.
* **Kategori Transaksi:** Pengelompokan pengeluaran (Makanan, Transportasi, Hiburan, dll).
* **Laporan Visual:** Chart batang dan pie untuk menganalisis kebiasaan finansial.
* **Ekspor Data:** Fitur ekspor laporan keuangan format ringkas.

## 5. Hasil & Dampak
Aplikasi ini terbukti membantu efisiensi pencatatan transaksi harian dengan kecepatan respon UI di bawah 100ms.
